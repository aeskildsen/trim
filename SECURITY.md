# Security policy

## Supported versions

trim has no releases. Only the latest version on `main` gets security fixes.

## Report a vulnerability

**Do not report a vulnerability in a public issue.**

[Report the vulnerability privately](https://github.com/aeskildsen/trim/security/advisories/new). Include:

- The steps that cause the problem
- The affected versions
- The possible effect

One person maintains this project when time permits. There is no fixed time for a response.
