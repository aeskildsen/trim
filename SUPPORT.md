# Support

## Find help

Before you open an issue, look in these places:

- **[README](../../#readme)**: installation and use
- **[Open issues](../../issues)**: known bugs and planned features
- **[Closed issues](../../issues?q=is%3Aissue+is%3Aclosed)**: problems that have a solution

## Report a bug

Use the [bug report template](../../issues/new?template=bug_report.yml). Include:

- The steps that cause the bug
- What you expected and what occurred
- The version of trim, git and your operating system

To repair a bug yourself, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Request a feature

Use the [feature request template](../../issues/new?template=feature_request.yml). Tell:

- The problem that you want to solve
- The solution that you propose
- How you will use it

## What you can expect

- One person maintains this project when time permits.
- There is no fixed time for a response.
- Report security problems privately. See [SECURITY.md](SECURITY.md).
